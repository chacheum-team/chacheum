# 차츰

운전할수록 나를 배우는 차. 깜빡이·조향·동승자 같은 차 신호로 내 운전 성향과 좋아하는 길의 특성을 배워, 경로 추천과 주행 중 안내를 나에게 맞춰 주는 Pleos Connect 앱임.

현대자동차그룹 차량용 앱 개발 공모전 출품작이며, 지금 개발 중임.

## 실행 방법

1. Pleos Connect Emulator v2.1.0을 켬.
2. Android Studio에서 이 프로젝트를 열고 Run을 누르거나, APK를 설치함.
   ```
   adb install -r apk/<APK 파일>
   ```
3. 시연 전에 Virtual Console에서 기어를 P로, 'Seat Occupancy'의 좌석을 모두 비움(그래야 '혼자'로 시작함).
4. 에뮬레이터 앱 목록에서 '차츰'을 엶.

### 시연 순서

1. **누가 운전해요?** 시동 직후 한 번 묻고, 5초 안에 답이 없으면 지난번 운전자로 시작함. '나'를 고름.
2. **첫 화면**: 요즘 배운 것(좌회전 1번을 피하려고 몇 분까지 더 쓰는지, 깜빡이 습관)과 나만의 주의 지점이 보임. [어디로 갈까요?]를 누르면 시연 목적지(서울숲)로 감.
3. **경로 고르기**: 후보 세 장(빠른 길, 내 길, 큰길 위주)과 '내 길' 추천, 까닭 한 줄(`좌회전 2번 줄이고 +3분`).
4. Virtual Console에서 뒷좌석을 Occupied로 바꾸면 상황 칩이 '아이 탐'이 되고 추천이 큰길 위주로 바뀜(`아이가 타서 좌회전 없는 길로 +6분`). 와이퍼를 켜면 '비', 전조등을 켜면 '밤'이 켜짐. 칩을 눌러 이번 주행에만 바로잡을 수 있음.
5. [내 길로 안내]를 누르면 모델이 그 선택을 배우고, 순정 내비에 경유지(성수역)를 넣어 경로를 요청함.
6. 기어를 D로 바꾸면 출발함. 기어 신호 없이 볼 때는 [기어 없이 출발]을 누름.
7. 주행 중에는 카드 한 장만 보임. 익숙한 길에서는 조용하고, 지난번에 지나쳤던 성수사거리 300m 앞에서 카드와 한 문장 음성으로 알림.
8. 주행 중 Virtual Console에서 깜빡이를 켜고 2~3초 뒤 조향각을 바꾸면 아래 시연 모드 줄에 '깜빡이 먼저'가 남음.
9. 도착 후 기어를 P로 바꾸면 **돌아보기**가 열림: 오늘 배운 것(`좌회전 1번 피하기 1.5분 → 1.8분`)과, 경로를 벗어난 곳이 일부러였는지 물음.
10. **나의 운전**: 운전 성향과 근거, 상황별 차이, 분 단위 길 취향(직접 고치기), 나만의 주의 지점.

- 시연 모드를 켜 두면 주행 진행·주의 지점·경로 이탈을 75초 시간표로 재생하고, 차 신호는 그대로 Virtual Console 값을 씀. 끄면 주행 진행과 도착을 순정 내비 이벤트로 받음.
- 왼쪽 위 '차츰' 로고를 길게 누르면 시연 도구(시연 모드 켜고 끄기, 처음 상태로, 최근 기록)가 열림.

## 디자인

- 차츰 디자인 시스템을 따름: Pleos Connect 색 값으로 만든 역할 토큰(주간·야간은 시스템 다크 모드를 따름), Pleos 글자 단계, Asta Sans 글꼴.
- 채운 버튼은 화면에 하나, 현대 블루·액티브 블루(`accent`)는 나에게서 배운 것(추천, 내 길 선, 주의 지점, 졸업 점)에만 씀.
- 세로 창(840×1184)과 가장 좁은 창(628×855)은 한 칸, 가로 창(1700×1184)에서 경로 고르기와 나의 운전은 두 칸.
- 주행 중에는 카드 한 장과 소리만 쓰고, 정차 전용 화면은 '정차 중에 볼 수 있어요'로 가림.

### 화면 캡처 테스트

JVM(Robolectric)에서 시연 흐름을 따라가며 화면을 PNG로 남김. 세로·가로·좁은 창과 주간·야간을 봄.

```
./gradlew :app:testDebugUnitTest
```

결과는 `app/build/screens/<창>/` 폴더에 생김.

## 테스트 환경

- Pleos Connect Emulator v2.1.0 (Android API 34 시스템 이미지)
- Android Studio, JDK 17, AGP 8.8.2, Kotlin 2.0.0, compileSdk·targetSdk 35, minSdk 28
- Pleos SDK: Vehicle 2.3.2, NaviHelper 3.0.5
- AAOS Car API: 기어(GEAR_SELECTION), 주행 규제(CarUxRestrictions)

## 구성

| 파일 | 하는 일 |
|---|---|
| `Model.kt` | 후보 경로, 운전자 프로필, 경로 선택 모델(조건부 로짓과 학습), 깜빡이 먼저 판정 |
| `App.kt` | 앱 상태, 화면 이동, 주행 흐름, 시연 모드 진행, 차 안 저장 |
| `CarSignals.kt` | Vehicle SDK·AAOS로 차 신호 받기 |
| `Navi.kt` | NaviHelper로 순정 내비에 경로·경유지 요청, 이벤트 받기 |
| `Speaker.kt` | 한 문장 음성 안내 |
| `Design.kt` | 디자인 토큰(글자 단계·간격·모서리), 글꼴, 아이콘, 로고, 경로 그림 |
| `Ui.kt` | 컴포넌트(버튼, 상황 칩, 경로 후보 카드, 주의 지점 카드, 프로필 행, 토스트, 팝업) |
| `Screens.kt` | 화면 여덟 장(누가 운전해요?, 질문 3개, 첫 화면, 경로 고르기, 주행 중 두 장, 돌아보기, 나의 운전) |
| `MainActivity.kt` | 창, 뒤로 가기, 토스트·팝업 층 |

### 경로 선택 모델

- 경로 r의 특성: 시간(10분 단위), 회전 수(좌회전+유턴), 익숙한 구간 비율, 어린이보호구역 수(아이가 탔을 때만)
- 효용: U(r) = Σ w_k·x_k(r), 고를 확률: P(r) = exp U(r) / Σ exp U
- 고른 경로 r*로 배우기: w ← w + η(x(r*) − Σ P(r)·x(r)) − λ(w − w₀), η = 0.3, λ = 0.1. w₀는 처음 질문 3개로 정한 시작값
- 상황 보정: 동승자·아이가 타면 회전 가중치, 아이면 보호구역 가중치, 비·밤이면 익숙함 가중치에 더함
- 좌회전 1번을 피하려고 더 쓰는 분 = w_l ÷ w_t (예: 혼자 1.5분 → 아이가 타면 3분)
- 주행 후 한마디(편했어요·별로였어요)도 같은 식으로 절반 세기만큼 반영함
